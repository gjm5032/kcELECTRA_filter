# KcELECTRA 기반 한국어 자살 위험 문장 분류 실험

본 프로젝트는 **한국어 문장 단위에서 자살 위험도를 분류하기 위한 모델**을 학습·평가하는 실험이다.  
KcELECTRA 기반 분류 모델을 사용하여, 내담자(유저)의 발화를 **Low / Moderate / High** 세 단계로 분류한다.

---

## 파일 구성

### `_kcELECTRA.ipynb`
- **모델 학습 코드와 평가 코드**가 포함된 Jupyter Notebook
- 학습 파트와 평가 파트는 **주석으로 명확히 구분**되어 있음
- 실행 환경(로컬, Colab 등)에 따라 **설치된 라이브러리 버전 차이로 오류가 발생할 수 있음**

---

### `train_data.jsonl`
- GPT API를 이용해 **합성(synthetic)으로 생성한 내담자 발화 데이터**
- 약 **670개의 시나리오**를 기반으로 생성된 문장들로 구성
- 각 항목은 하나의 내담자 발화를 의미함

---

## 라벨 정의

본 프로젝트에서는 자살 위험도를 다음 **3단계로 정의**한다.

| 라벨 | 값 | 의미 |
|----|----|----|
| Low | 0 | 일반적인 감정 표현, 평범한 우울감, 일상적인 상태 |
| Moderate | 1 | 심리적 어려움이 뚜렷하지만 즉각적인 자살 위험은 아님 |
| High | 2 | 즉각적인 자살 위험이 의심되는 상태 |

---

## 현재 모델 상태

- 전반적인 평가 지표 기준으로 **분류 성능은 양호**
- 명확한 고위험 문장은 대부분 정확히 탐지
- 일상적인 문장과 애매한 표현에 대해서도 비교적 안정적인 분류를 수행

그러나 아래와 같은 **한계점이 확인됨**.

---

## 확인된 문제점 (오탐 사례)

다음과 같이 **직관적으로는 “괜찮아 보이는 문장”임에도 불구하고**,  
모델이 **High(2)** 로 분류하는 오탐(false positive)이 발생함.

예시:
- `그 생각을 접었어`
- `힘들었지만 이제는 괜찮아`
- `지금은 그런 생각 안 해`

이러한 문장들은 **과거의 위험을 회상하거나, 회복 상태를 표현하는 문장**임에도  
모델이 자살 관련 키워드에 과도하게 반응하여 High로 분류하는 경향을 보임.

---

## 원인 분석

- 학습 데이터가 **GPT를 통해 생성된 합성 데이터**라는 한계가 있음
- 여러 페르소나를 부여하여 데이터를 생성했지만,
  - 실제 인간 발화에서 나타나는 **회복·완화 표현의 다양성**을 충분히 반영하지 못함
- 그 결과 모델이
  - 특정 단어(예: *접다*, *괜찮아*, 과거형 표현 등)에 **과적합(overfitting)** 된 것으로 판단됨
- 특히 **“현재 위험”과 “과거 위험 이력”을 명확히 구분하지 못하는 문제**가 확인됨

---

## 향후 개선 방향

- 회복·완화·과거 회상 표현을 포함한 문장을 추가로 수집 또는 생성하여
  - 오탐 방지용 데이터로 활용
- 모델 학습 외에도
  - **추론 단계에서 규칙 기반 보정 로직**을 병행
    - 예: 회복 표현이 포함된 경우 High → Moderate로 조정
- 장기적으로는
  - “현재 고위험”과 “과거 고위험 이력”을 구분하는 **라벨 체계 확장**도 고려 가능
